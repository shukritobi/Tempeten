# WhatsApp Message for Tempeten

## Recommended message

Salam Puan Fatin, saya Shukry. Saya ternampak Tempeten di Threads dan saya suka konsep tempe daun homemade, terutama cara puan buat secara small batch dengan pilihan Classic, Fusion dan Mini Goodies.

Saya perasan proses order sekarang menggunakan Tally, WhatsApp dan semakan delivery secara berasingan. Jadi saya sudah siapkan satu demo awal khas untuk Tempeten yang satukan semuanya dalam satu sistem:

- katalog produk dan bundle
- pilihan batch Jumaat, Sabtu atau Isnin dengan cutoff pre-order 4 hari
- pickup Banting atau Seri Kembangan
- semakan kadar dan tempahan Lalamove
- pembayaran Billplz
- semakan status order untuk pelanggan
- dashboard untuk puan urus bayaran, jumlah produksi, pickup dan delivery

Tujuannya supaya pelanggan lebih mudah order dan puan tak perlu ulang semak borang, payment dan rider secara manual satu-satu.

Ini demo awalnya:
https://shukritobi.github.io/Tempeten/

Boleh saya tunjukkan aliran sistem ini dalam call ringkas 10 minit? Saya juga nak pastikan harga, berat produk dan jadual pickup yang saya masukkan adalah betul.
